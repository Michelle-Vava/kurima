# Design mockups

Static HTML, not wired to the app. Open the `.html` files or look at the `.png`s.
Regenerate the screenshots with `node scripts/mockups.mjs`.

Every number is real: Harare, 3 November 2026, from Open-Meteo. They show the screen as it
would look *after* Stage 1 of [BUILD-ORDER.md](../../BUILD-ORDER.md) adds water balance, soil
temperature and forecast confidence, so the layouts have something worth laying out.

| | Direction | Leads with |
|---|---|---|
| **A** | Verdict-led | One answer in a dark block, four tiles, everything else collapsed |
| **B** | Dashboard grid | Compact verdict strip, then panels with small visuals, more on screen at once |
| **C** | Season-timeline-led | Where today sits in the season; the verdict is a consequence of that |
